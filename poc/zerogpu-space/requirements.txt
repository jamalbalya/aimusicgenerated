# Dependencies for the ACE-Step 1.5 ZeroGPU proof of concept.
#
# This is NOT a copy of ACE-Step's requirements.txt. ACE-Step is vendored as
# source and put on sys.path by app.py, so pip never reads its dependency list
# and never tries to build the packages that cannot build here. Every version
# below is either ACE-Step's own stated constraint or a version that satisfies
# both ACE-Step and ZeroGPU; nothing is guessed. See README.md for the full
# rationale of every deviation.
#
# Removed from ACE-Step's list, and why:
#   flash-attn    bare sdist, and the ZeroGPU build phase has no nvcc, so it
#                 cannot compile. Not needed: initialize_service() takes
#                 use_flash_attention and defaults it to False, and app.py
#                 passes False explicitly.
#   nano-vllm     installed from a local path, and only used by the vLLM LM
#                 backend. We run backend="pt", ACE-Step's own universal
#                 fallback and its README's recommendation for the 0.6B LM.
#   triton        a nano-vllm dependency; goes with it.
#   mlx, mlx-lm   Apple Silicon only.
#   triton-windows, the Windows flash-attn wheel
#                 Windows only.
#   peft, lycoris-lora, lightning, tensorboard
#                 LoRA training. This POC only generates. peft is kept because
#                 ACE-Step's LoraManagerMixin is part of the handler class.
#   spaces        HF pins its own version; a pin here breaks the build.
#
# Changed from ACE-Step's list, and why:
#   torch         ACE-Step pins 2.10.0+cu128 from download.pytorch.org. 2.10.0
#                 from PyPI is the same release and is on ZeroGPU's supported
#                 list; taking it from PyPI avoids an extra index in a build we
#                 cannot debug interactively.
